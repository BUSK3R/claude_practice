# Study-02: 할 일 관리 (Todo App)

HTML, CSS, 순수 JavaScript로 만든 할 일 관리 웹 앱입니다. 빌드 도구나 외부 라이브러리 없이 브라우저만 있으면 동작하며, 데이터는 브라우저의 `localStorage`에 저장되어 새로고침해도 유지됩니다.

## 기능

- **할 일 추가** — 제목을 입력하고 카테고리(업무 / 개인 / 공부)를 골라 추가합니다.
- **완료 체크** — 체크박스로 완료 상태를 켜고 끕니다.
- **수정** — 제목을 더블클릭하거나 ✎ 버튼을 누르면 수정할 수 있습니다. `Enter`나 포커스 이동으로 저장하고, `Esc`로 취소합니다.
- **삭제** — ✕ 버튼으로 항목을 삭제합니다.
- **카테고리 필터** — 전체 / 업무 / 개인 / 공부 탭으로 목록을 걸러 봅니다.
- **진행률 표시** — 전체 할 일 중 완료한 비율을 퍼센트와 진행 바로 보여줍니다. 필터와 관계없이 전체 항목 기준으로 계산합니다.

## 구성

- `index.html` — 페이지 구조 (헤더와 진행률, 입력 폼, 필터 탭, 할 일 목록)
- `app.js` — 추가/완료/수정/삭제, 필터링, 진행률 계산, `localStorage` 저장·불러오기 로직
- `style.css` — 스타일. 색상과 모서리 둥글기는 `:root`의 CSS 변수로 관리하며, 카테고리마다 색이 다릅니다.

## 실행 방법

`index.html`을 브라우저로 열면 바로 실행됩니다. 따로 설치할 것은 없습니다.

## 데이터 저장

할 일 목록은 `localStorage`의 `todos` 키에 JSON 배열로 저장됩니다. 각 항목의 형식은 다음과 같습니다.

```json
{
  "id": "문자열 (시간 + 난수로 생성)",
  "title": "할 일 제목",
  "category": "업무 | 개인 | 공부",
  "completed": false,
  "createdAt": "ISO 8601 형식의 생성 시각"
}
```

불러올 때 이 형식에 맞지 않는 항목은 버리고, 저장된 데이터가 손상되어 있으면 빈 목록으로 시작합니다.

## 주의사항

- 데이터는 브라우저마다 따로 저장됩니다. 다른 브라우저나 기기에서는 같은 목록이 보이지 않고, 브라우저의 사이트 데이터를 지우면 목록도 함께 사라집니다.
- 카테고리를 추가하거나 바꾸려면 `index.html`의 `<select>` 옵션과 필터 탭 버튼, 그리고 `style.css`의 카테고리 색상을 함께 고쳐야 합니다.
