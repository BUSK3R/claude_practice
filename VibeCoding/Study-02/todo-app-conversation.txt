  아쉬운 점

  1. 전역 단축키가 없습니다.
     - 예를 들어 /나 Ctrl+K로 입력창에 포커스를 주는 기능이 없습니다.
     - 필터 전환 단축키(1~4)도 없습니다.
     - 키보드 중심으로 쓰는 사용자에게는 마우스 의존도가 높습니다.
  2. 수정·삭제 버튼이 항상 보입니다.
     - 데스크톱 앱은 보통 항목에 호버할 때만 보여 줘서 화면을 깔끔하게
       유지합니다.
     - 지금은 모든 행에 ✎ ✕가 늘 표시됩니다.
  3. 삭제 확인에 confirm()을 씁니다 (app.js:132).
     - 브라우저 기본 모달이라 흐름이 끊깁니다.
     - 한 번 지운 항목을 되돌릴 방법(실행 취소)도 없습니다.
  4. "완료 항목 모두 삭제"에는 확인이 없습니다 (app.js:140).
     - 개별 삭제는 확인하는데 일괄 삭제는 바로 지워서 일관성이 없습니다.
  5. 큰 화면(1440px 이상)에서는 본문이 왼쪽으로 쏠립니다.
     - .content가 max-width: 1100px인데 가운데 정렬이 없어서, 와이드
       모니터에서는 오른쪽에 빈 공간이 크게 남습니다.
  6. 사이드바 폭이 고정이고 폰트가 작습니다.
     - 320px로 고정이고, 일부 텍스트가 12~13px입니다 (배지, 진행률 문구).
     - 데스크톱 기준으로는 조금 작은 편입니다.
  7. 마우스 포인터 정밀도를 활용하지 못합니다.
     - 항목 순서를 바꾸는 드래그 앤 드롭이 없습니다.
     - 완료 상태를 토글할 때 20px 체크박스를 직접 눌러야 하고, 행 전체는 클릭
       대상이 아닙니다.
  8. 스타일 규칙에 작은 결함이 있습니다.
     - .icon-btn:hover가 .icon-btn의 기본 규칙보다 앞에 있습니다 (style.css:261
       vs 274). 지금은 문제가 없지만 순서 때문에 나중에 덮어쓰기 오류가 생기기
       쉽습니다.
     - .filter-btn.active 위에서 hover 배경이 겹칠 가능성은 낮지만 확인이
       필요합니다.

  개선 우선순위 제안

  1. / 또는 Ctrl+K로 입력창 포커스, 1~4로 필터 전환 (구현이 작고 체감이 큼)
  2. 수정·삭제 버튼을 행 호버 및 :focus-within 때만 표시
  3. .content에 margin: 0 auto 또는 중앙 정렬 추가
  4. confirm() 대신 "실행 취소" 토스트로 교체
  5. 행 클릭으로 완료 토글, 필요하면 드래그 앤 드롭 정렬 추가

  수정하지 않았습니다.
