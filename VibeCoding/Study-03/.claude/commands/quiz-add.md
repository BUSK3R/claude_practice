questions.js에 새 퀴즈 문제 1개를 추가해 줘.

## 인자 처리
- `$1`은 카테고리, `$2`는 난이도야.
  - 카테고리: `history`(한국사), `science`(과학), `geography`(지리), `general`(일반상식)
    - 한글 이름(예: 한국사, 과학)으로 입력해도 해당 카테고리로 해석해.
  - 난이도: `E`(쉬움), `M`(보통), `H`(어려움)
    - 한글 이름(쉬움, 보통, 어려움)이나 소문자(e, m, h)로 입력해도 해석해.
- `$1`이나 `$2`가 비어 있거나 위 값에 해당하지 않으면 추가하지 말고 사용법(`/quiz-add <카테고리> <난이도>`)과 사용 가능한 값을 알려 줘.

## 작성 전 확인
- `questions.js`를 읽고 해당 카테고리의 기존 문제(주제, 보기, 정답 위치)를 파악해.
- 기존 문제와 주제·정답이 겹치지 않게 새 문제를 만들어.
- 난이도 기준은 기존 문제를 참고해.
  - E: 누구나 아는 상식 / M: 학습한 내용 / H: 세부 지식이나 헷갈리기 쉬운 내용

## 형식 (기존 문제와 동일하게)
- 해당 카테고리 블록의 마지막 문제 뒤에 추가해. 마지막 카테고리(`general`)에 추가할 때는 배열 끝의 쉼표 처리에 유의해.
- id는 카테고리 접두사(`h`, `s`, `g`, `n`) + 두 자리 순번으로, 해당 카테고리의 다음 번호를 사용해. (예: `h10` 다음은 `h11`)
- 난이도 주석은 `category: "..."` 뒤에 `// E`, `// M`, `// H` 형태로 붙여.
- 필드 순서와 들여쓰기는 기존 문제와 같게 해.

```js
  { id: "h11", category: "history", // M
    question: "...",
    choices: ["...", "...", "...", "..."],
    answerIndex: 0,
    explanation: "..." },
```

- 보기는 정확히 4개, `answerIndex`는 0~3.
- 정답 위치는 해당 카테고리 기존 문제의 분포를 보고, 덜 쓰인 번호로 정해.
- 오답 보기는 그럴듯하되 정답이 하나뿐이어야 해.
- 해설은 한두 문장으로 정답의 근거를 적어.

## 검증 가이드라인 (CLAUDE.md, 반드시 지킬 것)
1. 정답이 하나뿐인가? 다른 해석이 가능하면 조건을 명시해. (예: 면적 기준, 2026년 기준)
2. 최상급 표현('가장', '최초', '최대' 등)에는 측정 기준을 명시해. (예: 지름 기준, 길이 기준)
3. 시간과 범위가 명확한가? 변할 수 있는 정보는 시점을 밝히고, 지리적·분류적 범위를 한정해.
- 추가하기 전에 위 세 항목을 스스로 점검하고, 사실 관계가 불확실한 내용은 문제로 내지 마.

## 결과 보고

- 해당 카테고리의 난이도 구성(E/M/H)이 상단 주석 기준(쉬움 3 / 보통 5 / 어려움 2)을 넘으면 알려 줘.
