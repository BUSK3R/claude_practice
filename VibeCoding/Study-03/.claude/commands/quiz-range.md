questions.js의 $1번부터 $2번까지의 문제를 검토하고, 난이도와 정답 분포를 확인해 줘.

## 검토 범위
- `$1`은 시작 번호, `$2`는 끝 번호이며 둘 다 포함해. (예: `/quiz-range 1 10` → 1번~10번)
- 번호는 `questions.js`의 `QUESTIONS` 배열에 나열된 순서(1부터 시작)를 기준으로 해. id의 숫자(예: `g03`의 03)가 아니라 전체 순번이야.
  - 결과 표에는 순번과 id를 함께 적어서 헷갈리지 않게 해.
- 인자 처리
  - `$1`이나 `$2`가 비어 있거나 숫자가 아니면 검토하지 말고 사용법(`/quiz-range <시작> <끝>`)을 알려 줘.
  - `$1`이 `$2`보다 크면 검토하지 말고 순서를 바꿔 입력하라고 알려 줘.
  - `$2`가 전체 문제 수보다 크면 마지막 문제까지만 검토하고, 그 사실을 알려 줘.
- 결과 첫 줄에 검토 범위를 밝혀 줘. (예: "검토 범위: 11번~20번 (10문제)")

## 난이도 확인
- 난이도는 각 문제 줄 끝의 주석 `// E`(쉬움), `// M`(보통), `// H`(어려움)을 기준으로 해.
- 범위 내 난이도별 문제 수와 비율을 표로 정리해.

| 난이도 | 문제 수 | 비율 |
|--------|---------|------|
| 쉬움(E) | | |
| 보통(M) | | |
| 어려움(H) | | |

- 파일 상단 주석의 기준(카테고리마다 쉬움 3 / 보통 5 / 어려움 2)과 비교해, 범위가 한쪽으로 쏠려 있으면 알려 줘.
- 주석이 없는 문제가 있으면 '미표기'로 따로 세고 순번을 알려 줘.

## 정답 분포 확인
- `answerIndex`(0~3)를 보기 번호 ①~④로 바꿔 범위 내 분포를 표로 정리해.

| 정답 위치 | 문제 수 | 비율 |
|-----------|---------|------|
| ① (0) | | |
| ② (1) | | |
| ③ (2) | | |
| ④ (3) | | |

- 다음을 점검해서 문제가 있으면 지적해.
  - 특정 번호에 정답이 과도하게 몰려 있는지 (균등 분포는 각 25% 안팎)
  - 같은 번호가 3문제 이상 연속되는지 (해당 순번 표시)
  - 보기 개수가 4개가 아니거나 `answerIndex`가 보기 범위를 벗어난 문제가 있는지
- 문제 수가 적은 범위(예: 8문제 미만)는 분포 편향 판단이 의미 없을 수 있으니 참고용이라고 덧붙여 줘.

## 마무리 요약
- 검토한 문제 수, 난이도 분포 한 줄 요약, 정답 분포 한 줄 요약, 발견된 문제 수를 정리해.
