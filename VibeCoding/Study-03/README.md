# 상식 퀴즈

- **실행**: `index.html`을 브라우저에서 열면 바로 실행됩니다. (외부 라이브러리·빌드·네트워크 없음)
- **규칙**: 한국사 → 과학 → 지리 → 일반상식 순서로 카테고리당 10문제, 총 40문제. 문제와 보기 순서는 매 판 섞입니다.
- **점수**: 정답 1개당 10점, 만점 400점. 한 번 고른 답은 바꿀 수 없고, 키보드는 1~4번(선택)과 Enter(다음)를 씁니다.
- **순위**: 브라우저 `localStorage`(`quizRanking`)에 최대 100건 저장, 순위표에는 상위 10개 표시. 같은 점수면 먼저 기록한 사람이 위입니다.
- **주의**: 퀴즈 도중 새로고침하면 진행 상황이 사라지고 시작 화면으로 돌아갑니다.
- **문제 추가**: `questions.js`의 `QUESTIONS` 배열에 `{ id, category, question, choices(4개), answerIndex(0~3), explanation }`을 추가합니다.
  `category`는 `history`, `science`, `geography`, `general` 중 하나이며, 카테고리마다 10문제씩 출제하므로 개수를 맞춰야 합니다.
